## Use aria-pressed for button filter chips in Evo framework packages

`packages/evo-react/src/filter-chip/filter-chip.tsx` › `EvoFilterChip` | 2026-08-17 | impact:high | effort:low

Evo React and `packages/evo-marko/src/tags/evo-filter-chip/index.marko` apply `aria-selected` to native button filter chips, but `aria-selected` is not supported on the button role. Skin stories and CSS documentation use the correct `aria-pressed` state. Change both framework components and their tests to emit `aria-pressed`, then render each default filter chip and verify its button exposes `aria-pressed="false"` and `"true"` as selection changes.

## Manage focus explicitly after deleting a chips combobox chip

`packages/ebayui-core/src/components/ebay-chips-combobox/component.ts` › `handleDelete` | 2026-08-21 | impact:high | effort:med

The Marko delete handler and `packages/ebayui-core-react/src/ebay-chips-combobox/chips-combobox.tsx` › `handleDelete` only update selected state. Focus movement currently depends on browser and DOM reconciliation behavior, so deleting a non-final chip may appear to focus the next chip while deleting the final chip can lose a meaningful focus target. Explicitly focus the next chip after deletion, or the combobox textbox when no next chip exists, then add browser tests that delete first, middle, and final chips and assert the active element after each deletion.

## Associate labels and descriptions in React Field stories

`packages/ebayui-core-react/src/ebay-field/__tests__/index.stories.tsx` › `DefaultInline` | 2026-08-21 | impact:high | effort:med

Most React Field stories render `EbayLabel` without a matching control `id`, and `WithDescription` renders `EbayFieldDescription` without IDs referenced by `aria-describedby`. Because `EbayField`, `EbayLabel`, and `EbayFieldDescription` provide layout only, these examples teach unassociated visible labels and descriptions. Add matching `htmlFor`/`id` and `aria-describedby` relationships throughout the stories, then update `index.spec.tsx` to query the textbox, switch, and checkbox by their visible accessible names.
