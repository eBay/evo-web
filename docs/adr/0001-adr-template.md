# 1. ADR Template

Date: 2026-01-28

## Status

Accepted

## Context

We need to record the architectural decisions made in Evo Web.

## Decision

We will use Architecture Decision Records, in the same format as [described by Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions) with the following changes only:

   1.  We will keep ADRs under docs/adr/NNNN-adr-title.md
   1.  Our titles DO NOT include the _decision_. For example, "2. Unit Testing Framework" or "3. CSS Naming Methodology".

## Consequences

See Michael Nygard's article, linked above.
