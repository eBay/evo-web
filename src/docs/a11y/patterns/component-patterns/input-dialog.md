## Introduction

The input dialog pattern is a specific type of [lightbox dialog](../disclosure/lightbox-dialog) that prompts a user for their input.&#x20;

The behaviour is similar to JavaScript's [window.prompt()](https://developer.mozilla.org/en-US/docs/Web/API/Window/prompt) method.

## Interaction Design

The input dialog inherits all base behaviour and interaction design from the modal [lightbox dialog](./lightbox-dialog.md) pattern. It's unique characteristic is that the input field should receive keyboard focus (e.g. "Your Max Bid" in the screenshot above).
