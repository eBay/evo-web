# When asked to follow an existing convention, copy it exactly and add nothing

Asked to make the menu deprecation notices follow the convention used for the
`fake-*` deprecation (an attention section-notice with a short message and a
link), the agent wrapped old and new markup samples inside the notice. The user
replied: "We don't need to replace markup; a simple message and a link to the new
page is plenty. And the notice should not be wrapped into a section with the
code." It cost a review round and a second edit of four pages.

Disposition: open, Arthur Khachatryan, raised 2026-11-13. Candidate: a CLAUDE.md
line saying that when a task names an existing pattern to follow, match its
content as well as its markup, and propose any addition separately.
